# Security audit checklist

## Access control
- [ ] Repository visibility and permissions reviewed
- [ ] Branch protection rules documented
- [ ] Least-privilege access confirmed for collaborators

## Pull-request workflow
- [ ] All changes flow through pull requests
- [ ] Peer review required before merge
- [ ] CI checks must pass before merge
- [ ] Audit trail of approvals preserved

## Secret management
- [ ] Secret scanning enabled and alerts reviewed
- [ ] No credentials committed to history

## Evidence
- [ ] Screenshots/logs collected for each checklist item
- [ ] Evidence log completed (see evidence-log.md)
